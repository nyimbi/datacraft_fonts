# Upstream sources

Every Datacraft face is a modified build of one of these fonts. All are released under the SIL Open Font License 1.1; each license sits next to its font files. Retrieved 2026-11-22.

|---|---|---|---|---|

| `upstream/stix-two-math/` | STIX Two Math | see `upstream_info.md` | `github.com/google/fonts`, `ofl/stixtwomath` | OFL 1.1, Reserved Font Name "TM Math" |
| `upstream/fira-sans/` | Fira Sans, Light to Bold with italics | see `upstream_info.md` | `github.com/google/fonts`, `ofl/firasans` | OFL 1.1 |
| `upstream/fira-math/` | Fira Math | 0.3.4 | `github.com/firamath/firamath`, release v0.3.4 | OFL 1.1 |
| `upstream/jetbrains-mono/` | JetBrains Mono (variable, wght 100 to 800) | see `upstream_info.md` | `github.com/google/fonts`, `ofl/jetbrainsmono` | OFL 1.1 |
