Concentration of a sum of bounded variables

Let X1,…,Xn be independent with ai≤Xi≤bi, and write Sn=∑i=1nXi. For every t>0, Hoeffding's inequality gives

Pr[Sn−𝔼Sn≥t] ≤ exp⁡(−2t2∑i=1n(bi−ai)2)

def hoeffding_bound(t: float, widths: list[float]) -> float:
	return math.exp(-2 * t**2 / sum(w * w for w in widths))
